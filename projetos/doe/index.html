Doe+

Plataforma que conecta doadores e instituições sem fins lucrativos

Sobre

O Doe+ é uma iniciativa de extensão do IF Baiano focada em ampliar a visibilidade de ONGs e instituições sem fins lucrativos.

Essa plataforma funciona como uma rede social das ONGs e instituições, onde possíveis doadores visualizam as instituições cadastradas, acompanhando o dia a dia, realizar doações e serem voluntários.

A minha atuação nesse projeto foi como Gerente de Projetos e UI/UX Design, alinhando a liderança dos times com a prototipação das interfaces do aplicativo.

Status: O aplicativo tem a primeira versão, porém não foi implementado na comunidade.

Desafio

  • Gerenciar uma equipe acadêmica em um projeto com stakeholders reais e curtos prazos
  • Equilibrar o desenvolvimento da equipe com a implementação de requisitos críticos, como sistemas de pagamento e segurança de dados
  • Projetar um design acessível e responsivo para facilitar o uso em dispositivos móveis e desktop
  • Implementar meios de pagamento como Pix e cartão
  • Permitir doações financeiras e materiais para as intituições
  • Expandir o engajamento das instituição através do app

Solução

  • Estruturação dos times de desenvolvimento
  • Acompanhamento das equipes, para que as entregas fossem entregues conforme o cronograma
  • Definir requisitos para o tratamento de dados sensíveis
  • Prototipação intuitiva das interfaces

Processo de Design

1. Levantamento de requisitos

Entrevista com a IPAM (Instituição de Amparo e Promoção ao Menor) para compreender as dores e objetivos da Instituição.

2. Divisão dos times

Reestruturação completa do MVP, passando dos wireframes até a interface final de alta fidelidade.

3. Fluxo de usuários

A equipe de Engenharia de Software juntos aos gestores definiram o fluxo de usuários com base nos requisitos coletados na IPAM.

4. Wireframes

Criação dos wireframes de baixa e média fidelidade no Figma, validados com a gestão do projeto.

5. Protótipos de alta fidelidade

Prototipação da interface final do aplicativo mobile/dektop

6. Desenvolvimento

O aplicativo foi desenvolvido com Reactjs e React Native, Firebase e Node.js com Express. Durante o desenvolvimento, os requisitos foram definidos no ClickUp.
